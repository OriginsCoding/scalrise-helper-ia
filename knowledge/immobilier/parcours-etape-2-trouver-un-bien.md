## Lien avec la rentabilité

Trouver le bon bien ne repose pas uniquement sur l'annonce ou l'emplacement.

Après avoir sélectionné une opportunité, l'utilisateur doit vérifier :

- le rendement brut ;
- le rendement net ;
- le cash-flow ;
- les charges ;
- le coût du financement.

L'outil **Calculs de rentabilité** permet de confirmer si le bien sélectionné est réellement rentable.
