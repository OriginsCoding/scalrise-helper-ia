# Ajouter un locataire

## Description

Cette fenêtre permet d'ajouter un nouveau locataire dans un bien immobilier.

Le locataire est automatiquement rattaché au bien actuellement ouvert.

Une fois créé, il apparaît dans l'onglet **Locataires** de la fiche du bien.

---

# Accès

Immobilier

→ Gérer mes biens

→ Sélectionner un bien

→ Ajouter un locataire

---

# Informations personnelles

Les informations suivantes peuvent être renseignées :

- Prénom
- Nom
- Email
- Téléphone

---

# Informations financières

Pour chaque locataire il est possible de définir :

- Loyer mensuel
- Charges mensuelles
- Dépôt de garantie
- Jour de paiement du loyer (1 à 31)

Ces informations seront utilisées pour :

- le suivi des loyers
- les statistiques
- les quittances
- les avis d'échéance

---

# Bail

Le bail comporte les informations suivantes :

- Date d'entrée
- Date de fin prévue (facultative)

Si aucune date de fin n'est renseignée, le bail est considéré comme en cours.

---

# Après création

Le locataire est automatiquement ajouté dans le bien.

Il devient visible dans :

- l'onglet Locataires
- les finances du bien
- les générations de quittances
- les documents administratifs

---

# Fonctionnalités liées

Après l'ajout d'un locataire, Scalrise permet notamment de :

- suivre les loyers mois par mois
- générer les quittances
- générer un bail
- générer un état des lieux
- générer un avis d'échéance
- générer une attestation d'hébergement
- consulter son historique lorsqu'il quitte le logement

---

# Remarques

Plusieurs locataires peuvent être associés à un même bien.

Cette fonctionnalité permet notamment de gérer :

- les colocations
- plusieurs appartements dans un même immeuble
- plusieurs locataires successifs grâce à l'historique
