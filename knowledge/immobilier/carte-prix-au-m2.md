# Carte des prix au m²

Tags : carte prix immobilier, carte des prix au m², prix immobilier par département, DVF, médiane nationale, département le plus cher, département le moins cher, recherche département, marché immobilier français, comparaison départements, prix médian, immobilier France

## Présentation

La page **Carte des prix au m²** permet de visualiser les prix immobiliers médians par département en France.

Elle s'appuie sur les données DVF et propose une carte interactive colorée afin de comparer rapidement les niveaux de prix entre les départements.

La fonctionnalité est accessible depuis :

**Immobilier → Carte des prix**

L'URL visible est :

`/real-estate/price-map`

## Objectif

Cette page permet notamment de :

- comparer les prix immobiliers entre départements ;
- repérer les zones les plus chères ;
- repérer les zones les moins chères ;
- rechercher un département précis ;
- obtenir une vue d'ensemble du marché immobilier français ;
- préparer une étude de zone avant un investissement immobilier.

## Carte interactive

La page affiche une carte de France découpée par département.

Chaque département est coloré selon son niveau de prix médian au m².

La légende visible indique une échelle allant approximativement :

- des départements les moins chers, en dessous de 1 000 €/m² ;
- jusqu'aux départements les plus chers, au-dessus de 10 000 €/m².

Les couleurs permettent de comparer visuellement les départements.

## Navigation sur la carte

La carte propose des contrôles de zoom :

- zoom avant ;
- zoom arrière.

L'utilisateur peut explorer la France et comparer les départements directement sur la carte.

La capture ne permet pas de confirmer toutes les interactions possibles au clic ou au survol d'un département.

Scalia ne doit pas inventer un comportement précis non documenté.

## Recherche d'un département

Un champ permet de rechercher un département.

Le libellé visible est :

> Rechercher un département...

Cette recherche permet de retrouver plus rapidement une zone précise dans la carte ou dans les données associées.

## Médiane nationale

La page affiche un indicateur intitulé **Médiane nationale**.

Cet indicateur correspond au prix médian national au m² calculé à partir des données disponibles.

La valeur affichée dépend de la période et des données chargées.

Scalia ne doit pas annoncer une valeur fixe comme vérité permanente.

## Départements les plus chers

La page affiche un classement **Top 5 – Plus chers**.

Il présente les cinq départements ayant les prix médians au m² les plus élevés dans les données disponibles.

La capture montre notamment des exemples comme :

- Paris ;
- Hauts-de-Seine ;
- Alpes-Maritimes ;
- Val-de-Marne ;
- Haute-Savoie.

Ces valeurs sont des données affichées au moment de la capture et peuvent évoluer.

## Départements les moins chers

La page affiche également un classement **Top 5 – Moins chers**.

Il présente les cinq départements ayant les prix médians au m² les plus faibles.

La capture montre notamment des exemples comme :

- Creuse ;
- Haute-Marne ;
- Indre ;
- Meuse ;
- Nièvre.

Ces valeurs peuvent évoluer avec les données utilisées.

## Source des données

La page indique que les prix sont basés sur les données DVF.

DVF signifie **Demandes de Valeurs Foncières**.

Les prix affichés correspondent à des statistiques calculées à partir de transactions immobilières enregistrées.

## Différence avec la page Prix au m²

La page **Prix au m²** permet d'effectuer une recherche détaillée à partir d'une adresse et d'analyser les transactions autour de cette adresse.

La page **Carte des prix au m²** donne plutôt une vue nationale et comparative par département.

Scalia doit distinguer les deux fonctionnalités :

- **Prix au m²** : recherche locale par adresse ;
- **Carte des prix au m²** : comparaison nationale par département.

## Cas d'utilisation

La carte peut être utilisée pour :

- comparer plusieurs départements avant un investissement ;
- identifier des zones plus accessibles ;
- repérer les marchés les plus chers ;
- obtenir une première vue d'ensemble du marché immobilier français ;
- choisir des départements à analyser ensuite plus précisément avec l'outil Prix au m².

## Limites documentaires

La capture ne permet pas de déterminer :

- la période exacte couverte par les données ;
- la fréquence de mise à jour ;
- le comportement exact lors d'un clic sur un département ;
- les éventuels filtres supplémentaires ;
- les règles de calcul détaillées de la médiane ;
- les éventuelles restrictions Free ou Premium.

Scalia ne doit pas inventer ces informations.
