# Les données DVF

Tags : DVF, Demandes de Valeurs Foncières, prix immobilier, ventes immobilières, base DVF, prix au m²

## Qu'est-ce que la base DVF ?

DVF signifie **Demandes de Valeurs Foncières**.

Il s'agit d'une base de données publique recensant les transactions immobilières réalisées en France.

Chaque transaction provient des actes de vente enregistrés par l'administration fiscale.

---

## À quoi servent les données DVF ?

Les données DVF permettent notamment de :

- estimer le prix d'un bien ;
- connaître le prix moyen au m² d'un secteur ;
- comparer plusieurs quartiers ;
- analyser les ventes récentes ;
- préparer un investissement immobilier.

---

## Comment Scalrise utilise les données DVF ?

Le module **Immobilier → Prix au m²** utilise les données DVF pour calculer :

- le prix médian au m² ;
- le prix moyen au m² ;
- le prix minimum ;
- le prix maximum ;
- le nombre de transactions ;
- la tendance des prix ;
- les transactions récentes autour d'une adresse.

Les résultats peuvent être filtrés selon :

- le type de bien ;
- le rayon de recherche ;
- la période étudiée.

---

## Les données DVF sont-elles officielles ?

Oui.

Les données DVF proviennent des ventes immobilières enregistrées par l'administration française.

---

## Les données sont-elles en temps réel ?

Non.

Les données DVF sont mises à disposition avec un délai après l'enregistrement des ventes.

Les transactions les plus récentes peuvent donc ne pas apparaître immédiatement.

---

# Questions fréquentes

## Que signifie DVF ?

DVF signifie **Demandes de Valeurs Foncières**.

---

## D'où viennent les prix affichés dans le module Prix au m² ?

Ils sont calculés à partir des transactions issues de la base publique DVF.

---

## Les prix DVF sont-ils des estimations ?

Non.

Les prix enregistrés dans la base DVF correspondent aux ventes réellement réalisées.

Les indicateurs affichés par Scalrise (prix moyen, prix médian, tendance...) sont ensuite calculés à partir de ces transactions.

---

## Puis-je connaître le prix au m² d'une adresse ?

Oui.

Le module **Immobilier → Prix au m²** permet de rechercher une adresse et d'obtenir automatiquement les statistiques DVF correspondantes.
