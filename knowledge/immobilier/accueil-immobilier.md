# Accueil du module Immobilier

## Objectif de la page

La page **Immobilier** centralise les fonctionnalités de Scalrise liées à la gestion, à l'analyse et au suivi des investissements immobiliers.

Le sous-titre affiché est :

> Gère tes biens, simule tes investissements et suis ta rentabilité.

Cette page sert de point d'entrée vers les différents outils immobiliers.

## Accès à la page

1. Ouvrir Scalrise.
2. Dans le menu latéral, cliquer sur **Immobilier**.
3. La page d'accueil du module immobilier s'ouvre à l'adresse `/real-estate`.

## Fonctionnalités disponibles

### Gérer mes biens

Cette rubrique permet de :

- ajouter des biens immobiliers ;
- modifier les informations d'un bien ;
- suivre les biens enregistrés dans Scalrise.

Le bouton **Accéder** ouvre la fonctionnalité correspondante.

### Gérer mes bailleurs

Cette rubrique permet de :

- créer des bailleurs ;
- modifier les informations d'un bailleur ;
- organiser les différents bailleurs utilisés dans Scalrise.

Un bien immobilier peut être associé à un bailleur.

Le bouton **Accéder** ouvre la fonctionnalité correspondante.

### Mon Parcours Immo

Cette rubrique propose une timeline consacrée aux acquisitions et aux projets immobiliers.

Le parcours est accessible en partie gratuitement.

Certaines étapes, notamment la partie finale ou avancée du parcours, nécessitent un abonnement Premium.

Scalia ne doit donc pas présenter l'intégralité de cette fonctionnalité comme exclusivement Premium.

Le bouton **Accéder** ouvre le parcours immobilier.

### Calculs de rentabilité

Cette rubrique permet d'effectuer des calculs liés à un investissement immobilier, notamment :

- le rendement brut ;
- le rendement net ;
- le cash-flow ;
- le retour sur investissement, ou ROI.

Le bouton **Accéder** ouvre les outils de calcul.

### Prix au m²

Cette rubrique affiche des prix immobiliers calculés à partir d'une adresse.

Les données sont basées sur les données DVF.

Le bouton **Accéder** ouvre l'outil de prix au mètre carré.

### Carte des prix

Cette rubrique donne accès à une carte interactive des prix immobiliers par département.

Le bouton **Accéder** ouvre la carte.

### Taux et simulation

Cette rubrique permet de simuler un financement immobilier, notamment :

- un prêt ;
- un taux d'intérêt ;
- des mensualités.

Le bouton **Accéder** ouvre l'outil de simulation.

## Règles d'accès connues

- **Mon Parcours Immo** comporte une partie gratuite.
- La partie finale ou avancée de **Mon Parcours Immo** est réservée aux utilisateurs Premium.
- La capture ne permet pas de confirmer le niveau d'accès exact des autres fonctionnalités.
- Scalia ne doit pas annoncer qu'une fonctionnalité est gratuite ou Premium lorsque cette information n'est pas présente dans la documentation.

## Exemples de réponses de Scalia

### Question : Que puis-je faire dans le module Immobilier ?

Scalia peut répondre :

> Le module Immobilier permet de gérer vos biens et vos bailleurs, suivre votre parcours immobilier, calculer la rentabilité d'un investissement, consulter les prix au m², explorer une carte des prix et simuler un prêt.

### Question : Mon Parcours Immo est-il Premium ?

Scalia peut répondre :

> Mon Parcours Immo est accessible en partie gratuitement. Les dernières étapes ou les contenus avancés nécessitent un abonnement Premium.

### Question : Où puis-je calculer mon cash-flow ?

Scalia peut répondre :

> Depuis le module Immobilier, ouvrez la rubrique « Calculs de rentabilité ». Elle regroupe notamment les calculs de rendement brut, de rendement net, de cash-flow et de ROI.

## Limites documentaires

La capture ne permet pas de déterminer :

- les routes exactes ouvertes par chaque carte ;
- les champs et formulaires présents dans les pages suivantes ;
- les restrictions précises des offres gratuites et Premium pour les autres outils ;
- les méthodes de calcul utilisées par chaque simulateur ;
- la fréquence de mise à jour des données DVF.

Scalia ne doit pas inventer ces informations.
