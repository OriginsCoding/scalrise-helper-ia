# Annonces de location

## Description

Scalrise permet de rattacher à un bien les liens des annonces publiées sur les sites de location (Leboncoin, SeLoger, PAP, Bien'ici, La Carte des Colocs…). Un clic ouvre l'annonce directement sur le site, dans un nouvel onglet.

Scalrise n'enregistre que le lien : il ne publie pas l'annonce et ne se connecte pas aux sites d'annonces.

## Bien loué en entier ou colocation

- **Bien loué en entier** : les annonces apparaissent dans la carte **Annonces** de la fiche du bien.
- **Colocation** : les annonces s'affichent sous chaque chambre libre, avec le bouton **Ajouter une annonce**. Une ligne **Bien entier** au-dessus des chambres accueille une annonce commune à tout le logement.

## Ajouter une annonce

1. Cliquer sur **Ajouter une annonce**.
2. Coller le lien de l'annonce (adresse en https uniquement) : le site est reconnu automatiquement.
3. Ajouter un libellé si besoin.

Pour un site qui n'est pas dans la liste, **Autre site…** permet de l'ajouter ; il est ensuite proposé pour les annonces suivantes.

## Gérer les annonces

Chaque annonce peut être ouverte, copiée, modifiée, déplacée vers une autre chambre ou supprimée.

## Chemin d'accès

- Depuis le menu : Menu latéral › **Immobilier** › carte **Gérer mes biens** › cliquer sur le bien › carte **Annonces** (en colocation : sous chaque chambre).
