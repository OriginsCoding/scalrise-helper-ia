# Générateur QR Code

Tags : QR Code, générateur QR Code, QR Code statique, QR Code dynamique, QR dynamique, QR gratuit, QR Premium, lien QR Code, modifier lien QR Code

## Présentation

Le Générateur QR Code permet de créer, sauvegarder et télécharger des QR Codes directement depuis Scalrise.

Il est accessible depuis :

**Outils → Générateur QR Code**

Deux types de QR Codes sont disponibles :

- QR Codes statiques ;
- QR Codes dynamiques.

## QR Codes statiques

Les QR Codes statiques sont entièrement gratuits et ilimités.

Pour créer un QR Code statique, il suffit de renseigner :

- un libellé ;
- un lien (URL).

Une fois généré, le QR Code peut être :

- prévisualisé ;
- téléchargé ;
- sauvegardé dans Scalrise.

Les QR Codes sauvegardés restent accessibles depuis la liste des QR Codes statiques.

Ils peuvent également être téléchargés ou supprimés.

## QR Codes dynamiques (Premium)

Les QR Codes dynamiques sont réservés aux utilisateurs **Premium**.

Le principe est simple :

- le QR Code (son image) reste toujours identique ;
- le lien de destination peut être modifié à tout moment.

Cela permet par exemple :

- d'imprimer un QR Code une seule fois ;
- de changer ultérieurement la page web vers laquelle il redirige ;
- d'utiliser un même QR Code pour différentes campagnes.

Les QR Codes dynamiques peuvent également afficher le nombre de scans réalisés.

## Fonctionnalités

Le générateur permet notamment de :

- créer un QR Code statique ;
- sauvegarder un QR Code ;
- télécharger un QR Code ;
- consulter la liste des QR Codes enregistrés ;
- supprimer un QR Code ;
- créer des QR Codes dynamiques (Premium) ;
- modifier la destination d'un QR Code dynamique sans changer son image.

## Gratuit ou Premium

### Gratuit

Les fonctionnalités suivantes sont accessibles gratuitement :

- création de QR Codes statatiques ;
- téléchargement des QR Codes ;
- sauvegarde des QR Codes statiques ;
- gestion des QR Codes statiques.

### Premium

Les fonctionnalités Premium comprennent :

- création de QR Codes dynamiques ;
- modification du lien de destination sans changer le QR Code ;
- suivi du nombre de scans.

## Limites

La documentation disponible ne précise pas :

- le nombre maximal de QR Codes pouvant être enregistrés ;
- les formats d'export disponibles ;
- les statistiques détaillées des QR Codes dynamiques.

Scalia ne doit pas inventer ces informations.
