## Qu'est-ce que Scalrise ?

Scalrise est une plateforme web destinée aux entrepreneurs, investisseurs et particuliers souhaitant centraliser la gestion de leur patrimoine, de leurs investissements et de leur productivité.

Elle regroupe plusieurs modules permettant de gérer l'immobilier, la bourse, les projets, les tâches, les habitudes et différents outils d'organisation.

Scalrise est une **application web** accessible depuis un navigateur. Ce n'est pas une application mobile native.

---

# Les modules disponibles

Scalrise est organisée autour de plusieurs grands modules.

## Immobilier

Le module Immobilier permet notamment de :

- gérer ses biens immobiliers ;
- gérer les bailleurs ;
- gérer les locataires ;
- suivre les loyers ;
- générer des quittances ;
- suivre les prêts immobiliers ;
- estimer un bien immobilier ;
- consulter la carte des prix au m² ;
- analyser les données DVF ;
- calculer la rentabilité d'un investissement ;
- suivre un parcours pédagogique complet d'investissement immobilier.

---

## Bourse

Le module Bourse permet de :

- suivre ses portefeuilles boursiers ;
- gérer ses positions ;
- suivre ses dividendes ;
- consulter les revenus encaissés ;
- analyser son portefeuille.

---

## Entrepreneuriat

Le module Entrepreneuriat permet de gérer son activité au quotidien.

Il comprend notamment :

- les habitudes ;
- les tâches ;
- les projets Kanban ;
- l'orchestrateur de tâches (Premium) ;
- le CRM ;
- les objectifs ;
- les contacts ;
- les notes.

---

## Productivité

Scalrise propose plusieurs outils pour améliorer son organisation :

- gestion des tâches ;
- suivi des habitudes ;
- gestion de projets ;
- Focus Workspace ;
- Pomodoro ;
- bloc-notes ;
- playlists YouTube de concentration.

---

## Outils

Les outils disponibles comprennent notamment :

- Focus Workspace ;
- Pomodoro ;
- playlists de concentration ;
- vidéo d'ambiance ;
- bloc-notes ;
- liste de tâches du jour.

---

# Fonctionnalités gratuites

Selon les modules, Scalrise propose de nombreuses fonctionnalités gratuites, notamment :

- gestion des habitudes ;
- gestion des tâches ;
- Focus Workspace ;
- une partie des outils immobiliers ;
- création de projets (avec certaines limites).

---

# Fonctionnalités Premium

Selon les modules, l'abonnement Premium permet notamment de débloquer :

- davantage de projets ;
- davantage de membres par projet ;
- l'Orchestrateur de tâches ;
- les reviews automatiques des tâches ;
- certains contenus pédagogiques ;
- certaines fonctionnalités avancées immobilières.

Les fonctionnalités Premium dépendent du module utilisé.

---

# À qui s'adresse Scalrise ?

Scalrise est conçu pour :

- les entrepreneurs ;
- les investisseurs immobiliers ;
- les investisseurs en bourse ;
- les freelances ;
- les indépendants ;
- toute personne souhaitant mieux organiser ses finances et sa productivité.
