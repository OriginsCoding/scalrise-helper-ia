# Application mobile et notifications sur le téléphone

## Description

Scalrise s'installe sur un téléphone ou un ordinateur comme une application : icône sur l'écran d'accueil, ouverture en plein écran, et notifications même quand Scalrise est fermé. Il n'y a rien à télécharger dans un store.

Tout se règle dans le profil, carte **Application et notifications**.

## Installer l'application

- **Android et ordinateur (Chrome, Edge)** : bouton **Installer** dans la carte Application et notifications. Sinon, depuis le menu du navigateur, choisir « Installer l'application ».
- **iPhone et iPad** : ouvrir Scalrise dans Safari, toucher **Partager**, puis **Sur l'écran d'accueil**.

L'application installée propose des raccourcis **Loyers du mois** et **Mes biens** (appui long sur l'icône).

Quand une nouvelle version de Scalrise est publiée, un message propose de recharger. Rien n'est rechargé pendant une saisie.

## Activer les notifications sur le téléphone

- Les notifications s'activent **appareil par appareil**, dans **Notifications sur cet appareil**.
- Le bouton **Envoyer une notification de test** vérifie que tout fonctionne.
- Sur **iPhone**, il faut d'abord installer l'application sur l'écran d'accueil (iOS 16.4 ou plus).
- Si les notifications sont bloquées par le navigateur, il faut les autoriser pour le site dans les réglages du navigateur.

## Ce qui est notifié

Toutes les notifications de Scalrise arrivent sur les appareils activés, par exemple :

- les échéances à venir (DPE, fin de bail, congé, prêt, taxe foncière, CFE) ;
- une révision de loyer qui peut être appliquée ;
- un bail ou un état des lieux signé par toutes les parties ;
- un nouveau dossier de candidature ;
- les annonces générales de Scalrise.

Un clic sur la notification ouvre la bonne page.

## Confidentialité

Les notifications n'affichent jamais de montant, de nom ni d'adresse sur l'écran verrouillé : elles indiquent seulement qu'il y a du nouveau.

## Pastille sur l'icône

Le nombre de notifications non lues s'affiche sur l'icône de l'application installée, même application fermée (iPhone iOS 16.4+, Android, Chrome et Edge sur ordinateur). Il disparaît une fois tout lu.
