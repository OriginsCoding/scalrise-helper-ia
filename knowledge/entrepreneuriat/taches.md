# Mes tâches

## Navigation

Entrepreneuriat → Mes tâches

ou directement depuis **Tâches** dans le menu latéral.

La page **Mes tâches** permet de gérer ses tâches, suivre sa charge de travail et organiser son planning.

---

# Fonctionnalités

Depuis cette page il est possible de :

- créer une tâche ;
- modifier une tâche ;
- supprimer une tâche ;
- marquer une tâche comme terminée ;
- consulter les tâches en cours ;
- consulter les tâches terminées ;
- filtrer les tâches ;
- visualiser les tâches sous forme de liste ;
- visualiser les tâches dans un calendrier ;
- analyser sa charge de travail ;
- définir son temps disponible par jour.

---

# Création d'une tâche

Une tâche peut contenir :

- un titre ;
- une description ;
- une priorité ;
- une catégorie ;
- une durée estimée ;
- une date d'échéance.

---

# Priorités

Les priorités disponibles sont :

- Basse
- Moyenne
- Haute
- Urgente

Les priorités permettent de mieux organiser les tâches selon leur importance.

---

# Tableau de bord

Le tableau de bord affiche notamment :

- le nombre de tâches en cours ;
- le nombre de tâches urgentes ;
- le nombre total de tâches ;
- les tâches restantes ;
- les tâches en retard.

---

# Charge de travail

Scalrise calcule automatiquement :

- le temps disponible par jour ;
- le temps planifié ;
- la charge quotidienne ;
- les dépassements de charge.

L'utilisateur peut définir le nombre d'heures disponibles chaque jour afin d'obtenir une estimation réaliste de sa charge de travail.

---

# Calendrier

Les tâches peuvent être consultées sous forme de calendrier mensuel.

Le calendrier permet de visualiser rapidement :

- les jours les plus chargés ;
- les tâches planifiées ;
- la répartition des priorités.

---

# Liste des tâches

La vue Liste permet :

- d'afficher toutes les tâches ;
- d'afficher uniquement les tâches en cours ;
- d'afficher uniquement les tâches terminées ;
- de supprimer toutes les tâches terminées.

---

# Offre gratuite

Toutes les fonctionnalités principales du module **Mes tâches** sont disponibles gratuitement.

Cela inclut notamment :

- création de tâches ;
- modification de tâches ;
- suppression de tâches ;
- calendrier ;
- gestion des priorités ;
- charge de travail ;
- suivi des retards.

---

# Offre Premium

L'offre Premium ajoute une **review hebdomadaire automatique**.

Chaque semaine, Scalrise envoie un bilan comprenant :

- les tâches terminées ;
- les nouvelles tâches créées ;
- les tâches restant à réaliser ;
- l'évolution globale de votre productivité.

L'offre Premium donne également accès à un bouton permettant d'ouvrir l'**Orchestrateur de tâches**.

L'Orchestrateur de tâches est un assistant intelligent qui aide à organiser, prioriser et planifier vos tâches.

# Questions utilisateurs

## Où se trouvent les tâches ?

Entrepreneuriat → Mes tâches.

Ou directement depuis **Tâches** dans le menu latéral.

---

## Comment créer une tâche ?

Cliquez sur **Nouvelle tâche**, remplissez les informations puis cliquez sur **Créer**.

---

## Peut-on modifier une tâche ?

Oui.

---

## Peut-on supprimer une tâche ?

Oui.

---

## Peut-on définir une priorité ?

Oui.

Les priorités disponibles sont :

- Basse
- Moyenne
- Haute
- Urgente

---

## Peut-on ajouter une échéance ?

Oui.

Chaque tâche peut posséder une date d'échéance.

---

## Peut-on estimer la durée d'une tâche ?

Oui.

Vous pouvez renseigner une durée estimée en minutes.

---

## Existe-t-il un calendrier ?

Oui.

Les tâches peuvent être consultées sous forme de calendrier.

---

## Peut-on voir les tâches en retard ?

Oui.

Le tableau de bord indique les tâches en retard ainsi que la charge quotidienne.

---

## Peut-on personnaliser son temps disponible ?

Oui.

Vous pouvez définir le nombre d'heures disponibles pour chaque jour de la semaine.

---

## Les tâches sont-elles gratuites ?

Oui.

Toutes les fonctionnalités principales du module sont disponibles gratuitement.

---

## Que débloque Premium ?

Premium ajoute :

- une review hebdomadaire automatique ;
- l'accès à l'Orchestrateur de tâches.

---

## Qu'est-ce que la review hebdomadaire ?

Chaque semaine, Scalrise génère un bilan comprenant :

- les tâches terminées ;
- les nouvelles tâches créées ;
- les tâches restant à réaliser ;
- l'évolution globale de votre productivité.

Cette fonctionnalité est réservée aux membres Premium.

---

## Qu'est-ce que l'Orchestrateur de tâches ?

L'Orchestrateur de tâches est un assistant intelligent qui aide à organiser, prioriser et planifier vos tâches.

Il est accessible depuis un bouton présent sur la page **Mes tâches**.

Cette fonctionnalité est réservée aux membres Premium.

---

## Où se trouve l'Orchestrateur de tâches ?

Depuis **Entrepreneuriat → Mes tâches**, un bouton permet d'ouvrir l'Orchestrateur de tâches.

Ce bouton est visible uniquement pour les membres Premium.

---

## Puis-je utiliser l'Orchestrateur de tâches gratuitement ?

Non.

L'Orchestrateur de tâches est une fonctionnalité Premium.

---

## L'Orchestrateur de tâches peut-il m'aider à organiser mes tâches ?

Oui.

L'Orchestrateur de tâches analyse vos tâches et vous aide à :

- les prioriser ;
- les organiser ;
- les planifier ;
- améliorer votre productivité.

---

## La review hebdomadaire est-elle disponible gratuitement ?

Non.

La review hebdomadaire est réservée aux membres Premium.
