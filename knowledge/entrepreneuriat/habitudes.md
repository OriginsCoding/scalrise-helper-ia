# Mes habitudes

## Navigation

Entrepreneuriat → Mes habitudes

La page **Mes habitudes** permet de créer, suivre et analyser ses habitudes afin d'améliorer sa régularité et sa productivité.

---

# Fonctionnalités

Depuis cette page il est possible de :

- créer une nouvelle habitude ;
- modifier une habitude existante ;
- supprimer une habitude ;
- choisir une fréquence quotidienne, hebdomadaire ou mensuelle ;
- attribuer une icône ;
- choisir une couleur ;
- définir le niveau d'effort (1 à 5 étoiles) ;
- ajouter une description facultative.

---

# Suivi quotidien

Le mode **Jour** affiche :

- les habitudes du jour ;
- le taux de progression quotidien ;
- le nombre d'habitudes réalisées ;
- les jours consécutifs (streak) ;
- les points gagnés.

Chaque habitude peut être cochée comme réalisée.

---

# Vue hebdomadaire

La vue **Semaine** permet de visualiser l'ensemble des habitudes sur une semaine.

Elle affiche :

- les jours réalisés ;
- les habitudes restantes ;
- la progression par jour.

---

# Vue mensuelle

La vue **Mois** propose plusieurs statistiques :

- carte de chaleur des réalisations ;
- progression par habitude ;
- tendance des 7 derniers jours ;
- évolution mensuelle ;
- classement des habitudes ;
- habitudes les mieux respectées ;
- habitudes à améliorer.

---

# Statistiques

La page calcule automatiquement :

- progression du jour ;
- progression de la semaine ;
- nombre de jours consécutifs ;
- total de points ;
- pourcentage de réussite par habitude.

---

# Création d'une habitude

Une habitude possède :

- un nom ;
- une description facultative ;
- une fréquence ;
- une couleur ;
- une icône ;
- un niveau d'effort.

# Questions utilisateurs

## Où se trouvent les habitudes ?

Entrepreneuriat → Mes habitudes.

## Comment créer une habitude ?

Cliquez sur **Nouvelle habitude**, renseignez les informations puis validez.

## Peut-on créer plusieurs habitudes ?

Oui.

## Peut-on modifier une habitude ?

Oui.

## Peut-on supprimer une habitude ?

Oui.

## Peut-on choisir une fréquence ?

Oui.

Les fréquences disponibles sont :

- Quotidienne
- Hebdomadaire
- Mensuelle

## Peut-on choisir une icône ?

Oui.

## Peut-on choisir une couleur ?

Oui.

## À quoi servent les étoiles ?

Les étoiles représentent le niveau d'effort demandé pour réaliser l'habitude.

## Comment suivre mes habitudes ?

Depuis les vues :

- Jour
- Semaine
- Mois

Oui.

La page affiche notamment :

- progression quotidienne ;
- progression hebdomadaire ;
- jours consécutifs ;
- points ;
- carte de chaleur ;
- classement ;
- évolution mensuelle.

Oui.

## Les habitudes nécessitent-elles Premium ?

Non.
