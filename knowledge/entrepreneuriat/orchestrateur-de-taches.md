# Orchestrateur de tâches

Tags : orchestrateur de tâches, tâches récurrentes, automatisation des tâches, tâches mensuelles, tâches trimestrielles, tâches annuelles, modèles de tâches, catégories de tâches, génération automatique, planification récurrente, tâches entrepreneur, tâches immobilier, comptabilité, URSSAF, TVA, quittances, loyers, abonnement Premium, productivité

## Présentation

L’**Orchestrateur de tâches** permet de préparer et générer des tâches récurrentes selon une fréquence définie.

Il centralise les tâches périodiques liées notamment :

- à l’entrepreneuriat ;
- à la comptabilité ;
- à l’immobilier ;
- au suivi administratif ;
- aux obligations mensuelles, trimestrielles ou annuelles.

Cette fonctionnalité est accessible depuis :

- **Entrepreneuriat → Orchestrateur de tâches** ;
- ou depuis la page **Mes tâches**, via le bouton dédié.

L’URL visible est :

`/entrepreneurship/task-orchestrator`

## Accès Premium

L’Orchestrateur de tâches est une fonctionnalité **entièrement Premium**.

L’offre gratuite ne permet pas d’utiliser cette page.

Scalia doit toujours préciser cette restriction lorsqu’un utilisateur demande s’il peut accéder à l’Orchestrateur de tâches gratuitement.

## Objectif

L’Orchestrateur permet de :

- créer des modèles de tâches ;
- organiser les tâches par catégorie ;
- définir une temporalité ;
- activer ou désactiver des tâches récurrentes ;
- générer les tâches pour la période ;
- éviter d’oublier les obligations régulières ;
- réutiliser les mêmes ensembles de tâches d’un mois ou d’une année à l’autre.

## Nombre de tâches activées

La page affiche le nombre total de tâches actuellement activées.

Un bouton **Générer les tâches** permet de créer les tâches correspondantes dans le module **Mes tâches**.

## Fréquences disponibles

Les captures montrent plusieurs temporalités :

- **Mensuel** ;
- **Trimestriel** ;
- **Annuel**.

Exemples visibles :

- rapprochement bancaire ;
- vérification des prélèvements ;
- factures fournisseurs ;
- justificatifs de dépenses ;
- saisie comptable.

### Entrepreneur mensuel

Exemples visibles :

- suivi du chiffre d’affaires ;
- relance des impayés ;
- factures en attente ;
- cotisations URSSAF ;
- TVA mensuelle ;
- trésorerie ;
- suivi des dépenses.

### Immobilier mensuel

Exemples visibles :

- entretien et travaux ;

Exemples visibles :

- bilan annuel ;
- archivage des documents ;

- révision annuelle des loyers.

## Activation d’une tâche

Chaque tâche peut être activée ou désactivée avec un interrupteur.

Une tâche activée est prise en compte lors de la génération.

Une tâche désactivée n’est pas générée.

## Informations d’une tâche

Chaque tâche peut afficher notamment :

- son nom ;
- sa priorité ;
- sa durée estimée ;
- sa fréquence ;
- sa catégorie ou son groupe.

Les priorités visibles incluent par exemple :

- Basse ;
- Moyenne ;
- Haute ;
- Urgente.

## Groupes de tâches

L’utilisateur peut créer des groupes dans une catégorie.

Un groupe permet de regrouper plusieurs tâches liées à un même sujet.

Exemples visibles :

- Appartement Comptabilité Rennes 1 ;
- Appartement Comptabilité Rennes 2 ;
- Appartement Comptabilité Quimper.

Chaque ligne d’un groupe peut être modifiée ou supprimée.

## Ajouter un groupe

Le bouton **Ajouter un groupe** permet de créer un nouveau groupe dans une catégorie.

Selon les captures, l’utilisateur peut choisir :

- un modèle existant ;
- un groupe vide ;
- un modèle personnalisé.

## Modèles personnalisés

La section **Modèles personnalisés** permet de créer des ensembles réutilisables de tâches.

Un modèle contient :

- un nom ;
- plusieurs lignes de tâches ;
- une priorité par tâche ;
- une durée estimée ;
- des actions de modification ;
- des actions de suppression.

Un modèle peut ensuite être utilisé pour créer rapidement un groupe de tâches.

## Créer un modèle

Pour créer un modèle personnalisé :

1. Ouvrir la section **Modèles**.
2. Renseigner un nom de modèle.
3. Ajouter les lignes de tâches.
4. Définir la priorité et la durée de chaque tâche.
5. Cliquer sur **Créer un modèle**.

## Générer les tâches

Le bouton **Générer les tâches** permet de transformer les tâches activées en tâches réelles dans le module **Mes tâches**.

Avant de générer, l’utilisateur peut :

- activer ou désactiver les tâches ;
- ajuster les groupes ;
- modifier les durées ;
- modifier les priorités ;
- choisir les modèles utiles.

## Différence avec Mes tâches

La page **Mes tâches** sert à gérer les tâches concrètes à réaliser.

L’**Orchestrateur de tâches** sert à définir des modèles et tâches récurrentes qui pourront être générés.

Scalia doit distinguer les deux fonctionnalités :

- **Mes tâches** : suivi quotidien des tâches existantes ;
- **Orchestrateur de tâches** : préparation et génération des tâches récurrentes.

## Cas d’utilisation

L’Orchestrateur peut être utilisé pour :

- préparer les obligations comptables mensuelles ;
- suivre les échéances fiscales ;
- organiser les tâches liées à plusieurs biens immobiliers ;
- automatiser la préparation des tâches récurrentes ;
- créer un modèle comptable par appartement ;
- centraliser les échéances mensuelles, trimestrielles et annuelles ;
- éviter de recréer manuellement les mêmes tâches chaque période.

## Limites documentaires

Les captures ne permettent pas de confirmer :

- le jour exact de génération des tâches ;
- si la génération est automatique ou toujours déclenchée manuellement ;
- les règles précises de duplication ;
- la gestion des tâches déjà existantes ;
- les notifications envoyées ;
- la synchronisation éventuelle avec un calendrier externe ;
- les permissions détaillées selon les rôles.

Scalia ne doit pas inventer ces informations.
