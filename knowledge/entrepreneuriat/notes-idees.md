# Notes & idées

## Navigation

Entrepreneuriat → Notes & idées

La page **Notes & idées** permet de capturer des idées, rédiger des notes en Markdown, organiser ses réflexions et créer des cartes mentales (Mind Map).

---

# Fonctionnalités

Depuis cette page il est possible de :

- créer une nouvelle note ;
- modifier une note ;
- supprimer une note ;
- rechercher une note ;
- ajouter des tags ;
- ajouter des images ;
- rédiger en Markdown ;
- créer une carte mentale (Mind Map) ;
- transformer une note en nœud de Mind Map ;
- transformer un nœud de Mind Map en note ;
- partager une note publiquement ;
- classer une note selon son état.

---

# États des notes

Les notes peuvent être classées dans les catégories suivantes :

- Brouillons ;
- Idées ;
- Validées ;
- Archives.

Les filtres permettent d'afficher uniquement les notes appartenant à une catégorie.

---

# Création d'une note

Une note possède :

- un titre ;
- un contenu au format Markdown ;
- un état ;
- des tags ;
- des images.

Le contenu est enregistré automatiquement.

---

# Éditeur Markdown

L'éditeur permet notamment :

- rédiger une note au format Markdown ;
- ajouter des images ;
- ajouter des tags ;
- modifier le statut de la note ;
- partager une note.

---

# Cartes mentales (Mind Map)

Chaque note peut être représentée sous forme de carte mentale.

Les cartes mentales permettent de :

- créer des nœuds ;
- supprimer des nœuds ;
- déplacer librement les nœuds ;
- relier plusieurs nœuds entre eux ;
- modifier la couleur des nœuds ;
- organiser visuellement les idées.

---

# Conversion Note / Mind Map

Une note peut être transformée en nœud d'une carte mentale.

Inversement, un nœud peut être transformé en note indépendante.

Cette fonctionnalité permet de passer facilement d'une prise de notes classique à une représentation visuelle des idées.

---

# Partage

Une note peut être rendue publique.

Chaque note publique possède une URL unique pouvant être partagée avec d'autres personnes.

Les visiteurs peuvent consulter la note sans accéder à votre espace personnel Scalrise.

---

# Recherche

Le champ de recherche permet de retrouver rapidement une note à partir :

- du titre ;
- du contenu ;
- des tags.

---

# Offre gratuite

La version gratuite permet :

- jusqu'à **15 notes** ;
- **1 note publique partageable**.

---

# Offre Premium

L'abonnement Premium permet :

- un nombre illimité de notes ;
- un nombre illimité de notes publiques partageables.

---

# Bonnes pratiques

Pour organiser efficacement vos idées :

- utilisez un titre clair pour chaque note ;
- ajoutez des tags afin de retrouver rapidement vos notes ;
- classez vos notes selon leur état (Brouillon, Idée, Validée ou Archive) ;
- utilisez les cartes mentales pour organiser des projets complexes ;
- transformez vos idées importantes en Mind Map afin de visualiser les liens entre elles.

# Questions utilisateurs

## Où se trouvent les Notes & idées ?

Entrepreneuriat → Notes & idées.

## Comment créer une note ?

Cliquez sur **Nouvelle note**, saisissez un titre puis rédigez votre contenu.

## Peut-on modifier une note ?

Oui.

## Peut-on supprimer une note ?

Oui.

## Peut-on écrire en Markdown ?

Oui.

Toutes les notes utilisent un éditeur Markdown.

## Peut-on ajouter des images ?

Oui.

Une ou plusieurs images peuvent être ajoutées à une note.

## Peut-on ajouter des tags ?

Oui.

Les tags permettent d'organiser et de retrouver plus facilement les notes.

## Peut-on créer une carte mentale ?

Oui.

Chaque note peut être affichée sous forme de Mind Map.

## Peut-on transformer une note en Mind Map ?

Oui.

Une note peut être convertie en nœud d'une carte mentale.

## Peut-on transformer un nœud de Mind Map en note ?

Oui.

Chaque nœud peut être transformé en note indépendante.

## Peut-on relier plusieurs nœuds ?

Oui.

Les nœuds peuvent être reliés afin de représenter les relations entre plusieurs idées.

## Peut-on déplacer les nœuds ?

Oui.

Les nœuds peuvent être déplacés librement dans la carte mentale.

## Peut-on changer la couleur des nœuds ?

Oui.

Chaque nœud peut recevoir une couleur différente afin de mieux organiser la carte mentale.

## Peut-on partager une note ?

Oui.

Une note peut être rendue publique grâce à une URL de partage.

## Combien de notes puis-je créer avec l'offre gratuite ?

La version gratuite permet de créer jusqu'à **15 notes**.

## Combien de notes publiques puis-je partager gratuitement ?

Une seule note publique peut être partagée avec l'offre gratuite.

## Que permet l'offre Premium ?

L'offre Premium permet de créer un nombre illimité de notes ainsi qu'un nombre illimité de notes publiques partageables.

## Les Notes & idées sont-elles disponibles gratuitement ?

Oui.

Le module est disponible gratuitement avec une limite de 15 notes et d'une note publique partageable.

## Puis-je utiliser les cartes mentales sans Premium ?

Oui.

Les cartes mentales sont disponibles dans la version gratuite.
