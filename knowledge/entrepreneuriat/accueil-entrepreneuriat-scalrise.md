# Accueil du module Entrepreneuriat

## Objectif de la page

La page **Entrepreneuriat** centralise les outils de Scalrise liés à l'organisation personnelle, à la gestion de projets, au suivi des objectifs et à la productivité.

Le sous-titre affiché est :

> Gérez vos projets, habitudes et objectifs pour atteindre le succès.

Cette page sert de point d'entrée vers les différents outils du module Entrepreneuriat.

## Accès à la page

1. Ouvrir Scalrise.
2. Dans le menu latéral, cliquer sur **Entrepreneuriat**.
3. La page d'accueil du module Entrepreneuriat s'ouvre à l'adresse `/entrepreneurship`.

## Fonctionnalités disponibles

### Gérer mes habitudes

Cette rubrique permet de suivre ses habitudes quotidiennes et de construire une routine durable.

Les éléments visibles indiquent notamment :

- le suivi quotidien ;
- la progression ;
- la création d'une routine ;
- l'accompagnement vers les objectifs.

Les catégories visibles sont :

- Quotidien ;
- Suivi ;
- Routine.

Le bouton **Accéder** ouvre la fonctionnalité correspondante.

### Gérer mes tâches

Cette rubrique permet d'organiser ses tâches et de prioriser ses actions.

Les éléments visibles indiquent notamment :

- la productivité ;
- l'organisation ;
- la gestion des tâches à faire.

Les catégories visibles sont :

- Productivité ;
- Organisation ;
- Todo.

Le bouton **Accéder** ouvre la fonctionnalité correspondante.

### Gérer mes objectifs

Cette rubrique permet de définir et de suivre des objectifs SMART.

Les éléments visibles indiquent notamment :

- la vision ;
- les indicateurs clés, ou KPI ;
- le suivi de progression.

Les catégories visibles sont :

- Vision ;
- KPI ;
- Progression.

Le bouton **Accéder** ouvre la fonctionnalité correspondante.

### Mes projets

Cette rubrique permet de gérer des projets entrepreneuriaux à l'aide de tableaux Kanban collaboratifs.

Les éléments visibles indiquent notamment :

- une organisation en Kanban ;
- des usages collaboratifs ;
- une approche agile.

Les catégories visibles sont :

- Kanban ;
- Collaboration ;
- Agile.

Le bouton **Accéder** ouvre la fonctionnalité correspondante.

### CRM

Cette rubrique permet de gérer les contacts, les opportunités et les activités commerciales.

Les éléments visibles indiquent notamment :

- les contacts ;
- le pipeline commercial ;
- le suivi des opportunités ;
- les activités commerciales.

Les catégories visibles sont :

- Contacts ;
- Pipeline ;
- Commercial.

Le CRM est actuellement en **bêta**, mais il est utilisable.

Scalia peut donc expliquer qu'il s'agit d'une fonctionnalité disponible, encore en cours d'amélioration.

Le bouton **Accéder** ouvre le CRM.

### Notes & Idées

Cette rubrique permet de capturer des idées, prendre des notes et développer sa créativité.

Les catégories visibles sont :

- Idées ;
- Brainstorm ;
- Notes.

Le bouton **Accéder** ouvre la fonctionnalité correspondante.

### Tableau de bord

Cette rubrique propose une vue d'ensemble de la productivité.

Les éléments visibles indiquent notamment :

- des statistiques ;
- des graphiques ;
- une vue globale de l'activité.

Les catégories visibles sont :

- Analytics ;
- Stats ;
- Vue globale.

Le **Tableau de bord est entièrement réservé aux utilisateurs Premium**.

Scalia ne doit pas présenter cette fonctionnalité comme partiellement gratuite.

Le bouton **Accéder** ouvre le tableau de bord.

### Focus Workspace

Cette rubrique propose un espace immersif de concentration.

Les éléments visibles indiquent notamment :

- un minuteur Pomodoro ;
- une playlist YouTube ;
- les tâches en cours ;
- des post-it.

Les catégories visibles sont :

- Focus ;
- Productivité ;
- Pomodoro.

Le bouton **Accéder** ouvre la fonctionnalité correspondante.

### Orchestrateur de tâches

Cette rubrique permet d'automatiser des tâches récurrentes.

Les exemples visibles concernent notamment :

- la comptabilité ;
- l'immobilier ;
- la fiscalité.

Les catégories visibles sont :

- Comptabilité ;
- Suivi ;
- Organisation.

L'**Orchestrateur de tâches est entièrement réservé aux utilisateurs Premium**.

Scalia ne doit pas présenter cette fonctionnalité comme partiellement gratuite.

Le bouton **Accéder** ouvre la fonctionnalité correspondante.

## Règles d'accès connues

- Le **Tableau de bord** est entièrement Premium.
- L'**Orchestrateur de tâches** est entièrement Premium.
- Le **CRM** est en bêta, mais il est utilisable.
- La capture ne permet pas de confirmer le niveau d'accès exact des autres fonctionnalités.
- Scalia ne doit pas annoncer qu'une autre fonctionnalité est gratuite ou Premium sans information supplémentaire.

## Exemples de réponses de Scalia

### Question : Que puis-je faire dans le module Entrepreneuriat ?

Scalia peut répondre :

> Le module Entrepreneuriat permet de gérer vos habitudes, tâches, objectifs, projets, contacts commerciaux, notes et idées. Il propose aussi un espace Focus, un tableau de bord de productivité et un orchestrateur de tâches récurrentes.

### Question : Le CRM est-il disponible ?

Scalia peut répondre :

> Oui. Le CRM est actuellement en bêta, mais il est utilisable. Il permet de gérer vos contacts, opportunités, activités commerciales et votre pipeline.

### Question : Le Tableau de bord est-il gratuit ?

Scalia peut répondre :

> Non. Le Tableau de bord du module Entrepreneuriat est entièrement réservé aux utilisateurs Premium.

### Question : L'Orchestrateur de tâches est-il Premium ?

Scalia peut répondre :

> Oui. L'Orchestrateur de tâches est entièrement Premium. Il permet d'automatiser des tâches récurrentes, notamment liées à la comptabilité, à l'immobilier ou à la fiscalité.

### Question : À quoi sert Focus Workspace ?

Scalia peut répondre :

> Focus Workspace est un espace de concentration qui regroupe notamment un minuteur Pomodoro, une playlist YouTube, vos tâches et des post-it.
