# Gérer mes objectifs

## Navigation

Entrepreneuriat → Gérer mes objectifs

La page **Gérer mes objectifs** permet de créer, suivre et mesurer des objectifs personnels ou professionnels à l'aide de la méthode SMART.

---

# Fonctionnalités

Depuis cette page il est possible de :

- créer un nouvel objectif ;
- modifier un objectif existant ;
- supprimer un objectif ;
- définir un objectif de résultat ;
- définir un objectif d'action ;
- choisir un horizon temporel ;
- définir une catégorie ;
- renseigner une valeur cible ;
- définir une unité ;
- choisir une date de début ;
- définir une date cible ;
- suivre la progression des objectifs.

---

# Types d'objectifs

Deux types d'objectifs sont disponibles :

## Objectif de résultat

Les objectifs de résultats correspondent aux résultats que vous souhaitez atteindre.

Exemples :

- atteindre 100 000 € de chiffre d'affaires ;
- obtenir 100 nouveaux clients ;
- réaliser 500 ventes.

---

## Objectif d'action

Les objectifs d'actions représentent les actions à effectuer régulièrement.

Exemples :

- publier trois contenus LinkedIn par semaine ;
- appeler dix prospects par jour ;
- consacrer deux heures au développement produit.

---

# Méthode SMART

Chaque objectif peut être défini selon la méthode SMART.

Les critères sont :

- Spécifique ;
- Mesurable ;
- Atteignable ;
- Réaliste ;
- Temporellement défini.

---

# Création d'un objectif

Un objectif possède :

- un titre ;
- une description ;
- un type ;
- un horizon temporel ;
- une catégorie ;
- une valeur cible ;
- une unité ;
- une date de début ;
- une date cible.

---

# Tableau de bord

La page affiche :

- le nombre total d'objectifs ;
- les objectifs actifs ;
- les objectifs terminés ;
- les objectifs d'actions ;
- les objectifs de résultats.

---

# Suivi des objectifs

Chaque objectif peut être suivi afin de connaître :

- son état ;
- sa progression ;
- sa date cible ;
- son avancement.

# Questions utilisateurs

## Où se trouvent les objectifs ?

Entrepreneuriat → Gérer mes objectifs.

## Comment créer un objectif ?

Cliquez sur **Nouvel objectif**, complétez les informations puis validez.

## Quelle est la différence entre un objectif de résultat et un objectif d'action ?

Les objectifs de résultats représentent ce que vous souhaitez atteindre.

Les objectifs d'actions représentent les actions que vous devez réaliser pour atteindre ces résultats.

## Puis-je modifier un objectif ?

Oui.

## Puis-je supprimer un objectif ?

Oui.

## Puis-je suivre la progression d'un objectif ?

Oui.

Chaque objectif possède un suivi de progression.

## Que signifie SMART ?

SMART signifie :

- Spécifique ;
- Mesurable ;
- Atteignable ;
- Réaliste ;
- Temporellement défini.
