# Accueil du module Bourse

## Objectif de la page

La page **Bourse** centralise les fonctionnalités de Scalrise liées au suivi des investissements boursiers, des portefeuilles et des dividendes.

Le sous-titre affiché est :

> Vue d'ensemble de ton portefeuille orienté dividendes.

Cette page sert de point d'entrée vers les différents outils boursiers de Scalrise.

## Accès à la page

1. Ouvrir Scalrise.
2. Dans le menu latéral, cliquer sur **Bourse**.
3. La page d'accueil du module Bourse s'ouvre à l'adresse `/stocks`.

## Fonctionnalités disponibles

### Suivi des dividendes

Cette rubrique permet d'estimer et de suivre les dividendes.

Les éléments visibles indiquent notamment :

- une estimation des dividendes par mois ;
- un affichage sous forme de graphique ;
- un accès rapide depuis le raccourci **Suivi des dividendes** dans le menu latéral.

Le bouton **Accéder** ouvre la fonctionnalité correspondante.

### Simulateur Patrimoine

Cette rubrique permet de réaliser des simulations patrimoniales.

Les éléments visibles indiquent notamment :

- des calculs d'intérêts composés ;
- des projections Monte Carlo.

Le bouton **Accéder** ouvre le simulateur.

### Portfolio

Cette rubrique permet de consulter une vue synthétique d'un portefeuille.

Les éléments visibles indiquent notamment :

- la valeur du portefeuille ;
- son allocation ;
- sa performance.

Le bouton **Accéder** ouvre la fonctionnalité correspondante.

### Mes Portefeuilles

Cette rubrique permet de gérer plusieurs comptes ou enveloppes d'investissement.

Les exemples visibles sont :

- le PEA ;
- le CTO ;
- les autres comptes d'investissement seront ajoutés dans le futur.

Le bouton **Accéder** ouvre la gestion des portefeuilles.

### Mon Parcours Bourse

Cette rubrique propose une timeline consacrée au parcours de l'utilisateur en tant qu'investisseur en bourse.

Le parcours est accessible en partie gratuitement.

Les premières étapes sont disponibles sans abonnement Premium.

La partie finale ou avancée du parcours nécessite un abonnement Premium.

Le badge **Premium** affiché sur la carte indique donc la présence de contenus Premium, mais ne signifie pas que l'intégralité du parcours est payante.

Scalia ne doit pas présenter **Mon Parcours Bourse** comme une fonctionnalité entièrement Premium.

Le bouton **Accéder** ouvre le parcours boursier.

### Explorateur Actions & ETF

Cette rubrique permet de rechercher des actions et des ETF.

Les critères visibles indiquent notamment une recherche par :

- enveloppe ;
- secteur ;
- rendement ;
- autres critères non détaillés dans la capture.

Le bouton **Accéder** ouvre l'explorateur.

## Règles d'accès connues

- **Mon Parcours Bourse** est accessible en partie gratuitement.
- Les premières étapes du parcours sont gratuites.
- La partie finale ou avancée nécessite un abonnement Premium.
- Le badge Premium indique la présence de contenus Premium, mais pas un accès entièrement payant.
- La capture ne permet pas de confirmer le niveau d'accès exact des autres fonctionnalités.
- Scalia ne doit pas annoncer qu'une autre fonctionnalité est gratuite ou Premium lorsque cette information n'est pas présente dans la documentation.

## Exemples de réponses de Scalia

### Question : Que puis-je faire dans le module Bourse ?

Scalia peut répondre :

> Le module Bourse permet de suivre vos dividendes, simuler l'évolution de votre patrimoine, consulter votre portfolio, gérer plusieurs portefeuilles, suivre votre parcours boursier et rechercher des actions ou des ETF.

### Question : Où puis-je suivre mes dividendes ?

Scalia peut répondre :

> Depuis le module Bourse, ouvrez la rubrique « Suivi des dividendes ». Elle permet d'estimer les dividendes par mois et de les visualiser sous forme de graphique.

### Question : Puis-je gérer plusieurs portefeuilles ?

Scalia peut répondre :

> Oui. La rubrique « Mes Portefeuilles » permet de gérer vos PEA, CTO et autres comptes d'investissement.

### Question : À quoi sert l'Explorateur Actions & ETF ?

Scalia peut répondre :

> L'Explorateur Actions & ETF permet de rechercher des titres selon différents critères, notamment l'enveloppe, le secteur ou le rendement.

### Question : Mon Parcours Bourse est-il Premium ?

Scalia peut répondre :

> Mon Parcours Bourse est accessible en partie gratuitement. Les premières étapes sont gratuites, tandis que la partie finale ou avancée nécessite un abonnement Premium.

## Limites documentaires

La capture ne permet pas de déterminer :

- les routes exactes ouvertes par chaque carte ;
- les champs et filtres précis de l'explorateur ;
- les méthodes de calcul du simulateur ;
- les données utilisées pour les projections Monte Carlo ;
- la méthode de calcul de la performance du portfolio ;
- les restrictions exactes entre l'offre gratuite et l'offre Premium ;
- les actions disponibles dans la gestion des portefeuilles.

Scalia ne doit pas inventer ces informations.
