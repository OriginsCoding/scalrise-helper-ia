# Simulateur Patrimoine

Tags : simulateur patrimoine, intérêts composés, monte carlo, simulation bourse, projection patrimoine, projection investissement, rendement, capital, versement mensuel, simulation financière, patrimoine futur, simulation long terme

## Présentation

Le Simulateur Patrimoine permet d'estimer l'évolution d'un patrimoine investi sur plusieurs années.

Il est accessible depuis :

**Bourse → Simulateur Patrimoine**

Deux modes de simulation sont proposés :

- Intérêts composés
- Monte Carlo

## Gratuit ou Premium

Le Simulateur Patrimoine est **entièrement gratuit**.

Les deux modes de simulation sont accessibles à tous les utilisateurs :

- simulation par intérêts composés ;
- simulation Monte Carlo.

Aucun abonnement Premium n'est nécessaire pour utiliser ces simulateurs.

## Simulateur d'intérêts composés

Le simulateur d'intérêts composés permet d'estimer la croissance d'un capital avec un rendement annuel fixe.

Les paramètres disponibles sont :

- capital initial ;
- versement mensuel ;
- taux de rendement annuel ;
- durée d'investissement.

Le résultat affiche notamment :

- l'évolution du patrimoine ;
- le capital investi ;
- les intérêts composés ;
- le capital final ;
- les intérêts gagnés ;
- le ratio gains / investissement ;
- un détail année par année.

Cette simulation est purement mathématique.

## Simulation Monte Carlo

Le mode Monte Carlo permet de simuler plusieurs milliers de scénarios possibles en intégrant une volatilité des marchés.

Les paramètres disponibles sont :

- capital initial ;
- versement mensuel ;
- rendement moyen annuel ;
- volatilité annuelle ;
- durée ;
- nombre de simulations.

Après le lancement de la simulation, Scalrise affiche notamment :

- le scénario pessimiste (5e centile) ;
- le scénario médian (50e centile) ;
- le scénario optimiste (95e centile) ;
- un graphique représentant la distribution des résultats.

Cette simulation sert uniquement à illustrer différents scénarios possibles.

Elle ne constitue pas une prévision.

## Fonctionnalités

Le simulateur permet de :

- comparer différents scénarios d'investissement ;
- estimer l'impact des versements mensuels ;
- visualiser la puissance des intérêts composés ;
- observer l'effet de la durée d'investissement ;
- comprendre l'impact de la volatilité grâce à Monte Carlo.

## Gratuit ou Premium

La documentation disponible ne précise pas si cette fonctionnalité est réservée aux utilisateurs Premium.

Scalia ne doit donc pas inventer cette information.

## Limites

Les résultats sont des simulations.

Ils ne garantissent pas les performances futures d'un investissement.

Les hypothèses retenues dépendent uniquement des paramètres renseignés par l'utilisateur.
