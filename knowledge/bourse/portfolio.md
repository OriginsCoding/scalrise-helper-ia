# Portfolio boursier

Tags : portfolio, portefeuille boursier, vue d'ensemble, actions, positions, allocation sectorielle, plus-value, moins-value, performance, rendement dividendes, valeur totale, capital investi, diversification, bourse, PEA, CTO

## Présentation

La page **Portfolio** est accessible depuis :

**Bourse → Portfolio**

Elle fournit une vue d’ensemble des investissements boursiers enregistrés dans Scalrise.

Elle permet de suivre la valeur du portefeuille, le capital investi, les performances et la répartition des positions.

## Indicateurs principaux

La page affiche notamment :

- la valeur totale du portefeuille ;
- le montant total investi ;
- la plus-value ou moins-value globale ;
- l’évolution de la journée ;
- le rendement moyen des dividendes ;
- le nombre de lignes détenues.

## Allocation par secteur

Le portfolio affiche une répartition des investissements par secteur d’activité.

Un score de diversification sectorielle permet d’évaluer la concentration du portefeuille.

Les secteurs visibles peuvent notamment inclure :

- services financiers ;
- énergie ;
- consommation cyclique ;
- services de communication ;
- santé ;
- services aux collectivités ;
- industrie.

## Répartition par action

Un graphique présente la répartition du portefeuille entre les principales positions.

Il permet de visualiser le poids de chaque ligne dans l’ensemble du portefeuille.

## Plus-values et moins-values

La page affiche les plus-values et moins-values par position.

L’utilisateur peut consulter les performances :

- en valeur monétaire ;
- en pourcentage.

## Détail des positions

Le tableau de détail affiche notamment :

- le symbole de l’action ;
- le nom de la société ;
- le secteur ;
- la quantité détenue ;
- le prix de revient unitaire ;
- le cours actuel ;
- l’évolution quotidienne ;
- le montant investi ;
- la valeur actuelle ;
- la plus-value ou moins-value ;
- le rendement du dividende ;
- le poids de la ligne dans le portefeuille.

## Actualisation des données

Un bouton **Actualiser** permet de mettre à jour les données du portefeuille.

La capture ne permet pas de confirmer la source exacte des cours ni leur fréquence de mise à jour.

Scalia ne doit pas inventer ces informations.

## Accès aux dividendes

Un bouton **Dividendes** permet d’accéder à la page de suivi des dividendes.

## Ajout de positions

Un bouton **Ajouter une position** permet d’enregistrer une nouvelle ligne dans le portefeuille.

Les positions peuvent être ajoutées :

- manuellement ;
- ou à l’aide d’un fichier CSV.

L’ajout des positions est détaillé dans le document `positions.md`.

## Absence de connexion bancaire ou broker

Scalrise ne se connecte pas directement aux banques, aux courtiers ou aux brokers pour importer automatiquement les positions.

Les données sont renseignées manuellement par l’utilisateur ou importées à partir d’un fichier CSV.

## Accès

La documentation fournie ne mentionne pas de restriction Free ou Premium spécifique pour la page Portfolio.

Scalia ne doit pas conclure qu’une fonctionnalité est gratuite uniquement parce qu’aucune restriction n’est affichée.
