# Explorateur Actions & ETF

Tags : explorateur actions, ETF, recherche action, recherche ETF, PEA, CTO, actions françaises, filtre actions, screener bourse, exploration bourse

## Présentation

L'Explorateur Actions & ETF permet de rechercher, filtrer et découvrir des actions et des ETF directement depuis Scalrise.

Il est accessible depuis :

**Bourse → Exploration Actions & ETF**

Cette fonctionnalité est entièrement gratuite.

## Fonctionnalités

L'explorateur permet notamment de :

- rechercher une action ou un ETF par son nom ou son symbole ;
- filtrer les résultats par type (Action ou ETF) ;
- filtrer par enveloppe fiscale (PEA ou CTO) ;
- filtrer par secteur d'activité ;
- filtrer selon le rendement du dividende ;
- trier les résultats selon différents critères.

Chaque fiche affiche notamment :

- le nom de la société ;
- le symbole boursier ;
- le rendement du dividende lorsqu'il est disponible ;
- le secteur ;
- l'indice de référence ;
- l'éligibilité PEA lorsque c'est le cas ;
- le nombre d'investisseurs Scalrise détenant cette valeur.

Un lien permet également d'ouvrir la valeur directement sur Boursorama pour obtenir davantage d'informations.

## Univers d'investissement

Pour le moment, l'explorateur est principalement orienté vers les **actions françaises éligibles au PEA**.

Quelques ETF sont également disponibles.

La documentation actuelle ne permet pas de confirmer la présence d'actions internationales ou d'autres marchés.

Scalia ne doit donc pas inventer cette information.

## Gratuit ou Premium

L'Explorateur Actions & ETF est entièrement gratuit.

Aucun abonnement Premium n'est nécessaire pour utiliser cette fonctionnalité.

## Limites

La documentation actuelle ne précise pas :

- le nombre exact de valeurs disponibles ;
- la fréquence de mise à jour des données ;
- les marchés internationaux disponibles ;
- la présence de tous les ETF européens.

Scalia ne doit pas inventer ces informations.
