# Mes portefeuilles

Tags : portefeuille, portefeuilles, bourse, pea, cto, compte titres, investissement, actions, créer portefeuille, gestion portefeuille

## Présentation

La page **Mes portefeuilles** est accessible depuis :

- **Bourse → Mes portefeuilles**

Elle permet de créer et gérer ses portefeuilles boursiers afin d'organiser ses investissements.

Cette fonctionnalité est **entièrement gratuite**.

---

# Fonctionnalités

L'utilisateur peut :

- créer un portefeuille ;
- modifier un portefeuille ;
- supprimer un portefeuille ;
- choisir un nom ;
- sélectionner le type de portefeuille.

---

# Types de portefeuille disponibles

Actuellement la documentation confirme la prise en charge de :

- **PEA (Plan d'Épargne en Actions)**
- **CTO (Compte-Titres Ordinaire)**

Ces deux types sont ceux actuellement documentés.

---

# Création d'un portefeuille

Lors de la création d'un portefeuille, il est possible de renseigner :

- un nom ;
- le type de portefeuille (PEA ou CTO) ;
- un courtier (optionnel) ;
- une couleur.

Une fois créé, le portefeuille pourra ensuite contenir les positions boursières correspondantes.

---

# Gratuit / Premium

Cette fonctionnalité est disponible **gratuitement**.

La documentation ne mentionne actuellement aucune limitation Free ou Premium concernant la gestion des portefeuilles.
