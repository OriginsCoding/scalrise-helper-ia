# Mes portefeuilles

## Présentation

La page **Mes portefeuilles** est accessible depuis :

- **Bourse → Mes portefeuilles**

Elle permet de créer et gérer ses portefeuilles boursiers afin d'organiser ses investissements.

Cette fonctionnalité est **entièrement gratuite**.

---

# Fonctionnalités

L'utilisateur peut :

- créer un portefeuille ;
- modifier un portefeuille ;
- supprimer un portefeuille ;
- choisir un nom ;
- sélectionner le type de portefeuille.

---

# Types de portefeuille disponibles

Scalrise propose les types suivants :

- **PEA** (Plan d'Épargne en Actions) et **PEA-PME** ;
- **CTO** (Compte-Titres Ordinaire) ;
- **PER** (Plan d'Épargne Retraite) ;
- **AV** (assurance-vie) ;
- **PEE**, **PEG** et **PERECO** pour l'épargne salariale (voir la fiche Épargne salariale : blocage, plafonds, abondement, déblocages anticipés).

Les positions acceptent des quantités décimales (par exemple 84,1 parts de fonds).

---

# Création d'un portefeuille

Lors de la création d'un portefeuille, il est possible de renseigner :

- un nom ;
- le type de portefeuille (PEA, CTO, PER, assurance-vie, PEE…) ;
- un courtier (optionnel) ;
- une couleur.

Une fois créé, le portefeuille pourra ensuite contenir les positions boursières correspondantes.

---

# Gratuit / Premium

La gestion des portefeuilles est disponible **gratuitement** jusqu'à **2 portefeuilles**.

Avec l'abonnement **Premium**, le nombre de portefeuilles est illimité.
