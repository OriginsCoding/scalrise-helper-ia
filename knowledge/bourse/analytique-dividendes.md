# Analytique des dividendes

Tags : analytique dividendes, analyse dividendes, rendement sur coût, yield on cost, yoc, dgr, croissance dividendes, capital récupéré, dividendes premium, revenus passifs, investissement, bourse, pea, cto

## Présentation

La page **Analytique des dividendes** est accessible depuis :

- **Bourse → Suivi des dividendes → bouton "Analyse"**

Cette fonctionnalité est **entièrement réservée aux abonnés Premium**.

Elle permet d'analyser les performances des dividendes perçus par rapport au capital investi et d'évaluer la rentabilité de chaque ligne du portefeuille.

---

# Fonctionnalités Premium

L'analytique des dividendes permet de :

- analyser les dividendes ligne par ligne ;
- comparer les dividendes de l'année en cours avec les années précédentes ;
- mesurer la croissance annuelle des dividendes (YoY) ;
- calculer le rendement sur coût (Yield On Cost / YoC) ;
- suivre la croissance des dividendes (DGR) ;
- connaître le total des dividendes reçus par valeur ;
- mesurer la part du capital déjà récupérée grâce aux dividendes ;
- suivre le capital total investi ;
- visualiser le montant total des dividendes perçus.

---

# Indicateurs disponibles

La page affiche notamment :

- total des dividendes de l'année ;
- capital investi ;
- total des dividendes perçus ;
- pourcentage du capital récupéré.

Pour chaque valeur du portefeuille, Scalrise affiche également :

- montant investi ;
- dividendes de l'année ;
- dividendes des années précédentes ;
- évolution annuelle (YoY) ;
- rendement sur coût (Yield On Cost) ;
- DGR (Dividend Growth Rate) ;
- total des dividendes encaissés ;
- pourcentage du capital récupéré.

---

# À quoi sert cette page ?

Cette page permet notamment de répondre aux questions suivantes :

- Mon investissement est-il déjà rentable grâce aux dividendes ?
- Quelle action rembourse le plus rapidement mon capital ?
- Quel est mon rendement réel sur mon prix d'achat ?
- Quels titres augmentent leurs dividendes chaque année ?
- Quelle ligne génère le plus de revenus passifs ?
- Quelle part de mon capital a déjà été remboursée par les dividendes ?

---

# Gratuit / Premium

## Gratuit

La page **Suivi des dividendes** permet de suivre :

- les dividendes reçus ;
- les dividendes à recevoir ;
- les statistiques ;
- les graphiques ;
- l'historique des dividendes.

## Premium

L'Analytique des dividendes ajoute :

- le rendement sur coût (YoC) ;
- l'évolution annuelle (YoY) ;
- le DGR ;
- le capital récupéré ;
- les analyses détaillées par ligne ;
- les indicateurs avancés de performance.
