# Suivi des dividendes

Tags : dividendes, revenus passifs, dividende, portefeuille, pea, cto, rendement, historique, analyse, revenus, estimation, graphique

## Présentation

La page **Suivi des dividendes** est accessible depuis :

- **Bourse → Suivi des dividendes**

> Accéder à « Suivi des dividendes »

L'URL visible dans la capture est de la forme :

`https://www.scalrise.com/stocks/dividends`

Elle permet de suivre les revenus générés par les dividendes de ses portefeuilles boursiers.

La majorité des fonctionnalités est disponible gratuitement.

---

# Fonctionnalités gratuites

La page permet notamment de :

- consulter l'estimation annuelle des dividendes ;
- visualiser le revenu mensuel estimé ;
- suivre les dividendes déjà reçus ;
- suivre les dividendes restant à recevoir ;
- consulter le rendement moyen du portefeuille ;
- connaître le nombre de positions détenues ;
- afficher les dividendes par mois, trimestre ou année ;
- consulter le détail des positions générant des dividendes ;
- visualiser la répartition par secteur ;
- visualiser la répartition géographique ;
- suivre son objectif annuel de revenus passifs ;
- filtrer les données par portefeuille (PEA ou CTO).

---

# Historique des dividendes

Le bouton **Historique** permet de :

- consulter l'ensemble des dividendes déjà perçus ;
- retrouver l'historique complet des versements ;
- exporter les graphiques au format PNG.

Cette fonctionnalité est disponible gratuitement.

---

# Analyse des dividendes

Le bouton **Analyse** est une fonctionnalité **Premium**.

Il permet d'obtenir une analyse des dividendes perçus en les comparant au montant investi afin d'évaluer la performance de l'investissement.

---

# Informations affichées

La page présente notamment :

- le total annuel estimé ;
- le revenu mensuel estimé ;
- les dividendes reçus ;
- les dividendes à recevoir ;
- le rendement moyen ;
- les positions concernées ;
- les dividendes estimés par position ;
- les prochains dividendes attendus ;
- les statistiques de répartition ;
- la progression vers l'objectif de revenus passifs.

---

# Gratuit / Premium

## Gratuit

- suivi complet des dividendes ;
- graphiques ;
- historique ;
- statistiques ;
- filtrage par portefeuille ;
- export PNG de l'historique.

## Premium

- analyse avancée des dividendes par rapport au capital investi.
