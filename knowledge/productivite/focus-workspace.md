# Focus Workspace

Tags : focus workspace, concentration, pomodoro, minuteur, timer pomodoro, musique de concentration, ambiance, vidéo de fond, feu de cheminée, café, jazz, pluie, forêt, synthwave, playlist YouTube, tâches du jour, bloc note, notes, deep work, productivité, outils, focus, espace de travail

## Présentation

Le **Focus Workspace** est un espace de travail conçu pour améliorer la concentration.

Il regroupe plusieurs outils dans une seule interface afin de limiter les distractions pendant une session de travail.

Cette fonctionnalité est accessible depuis :

- **Outils → Focus Workspace**

L'URL visible est :

`/tools/focus`

## Accès

Le **Focus Workspace est entièrement gratuit**.

Aucun abonnement Premium n'est nécessaire pour utiliser cette fonctionnalité.

## Fonctionnalités principales

Le Focus Workspace rassemble plusieurs outils :

- un minuteur Pomodoro ;
- une vidéo d'ambiance en arrière-plan ;
- une playlist YouTube personnalisée ;
- une liste des tâches du jour ;
- un bloc-notes.

L'objectif est de disposer d'un environnement complet de concentration sans changer d'application.

## Ambiances vidéo

Le Focus Workspace permet de diffuser une vidéo d'ambiance en plein écran.

Parmi les ambiances visibles :

- Feu de cheminée ;
- Lofi Hip Hop ;
- Café Jazz ;
- Pluie relaxante ;
- Forêt & oiseaux ;
- Synthwave.

Ces vidéos servent uniquement d'ambiance de travail.

## Contrôles vidéo

Les contrôles permettent notamment :

- lecture / pause ;
- retour au début ;
- redémarrage ;
- gestion de la progression ;
- réglage du volume ;
- réglage de l'opacité de la vidéo.

## Playlist personnelle

L'utilisateur peut ajouter ses propres vidéos YouTube.

Chaque entrée comporte :

- un lien YouTube ;
- un nom (optionnel).

La playlist personnelle permet de retrouver rapidement ses vidéos favorites.

## Pomodoro

Le Focus Workspace intègre un minuteur Pomodoro.

Les captures montrent notamment :

- un timer de 25 minutes ;
- un bouton Démarrer ;
- les contrôles suivants / précédent ;
- le nombre de sessions réalisées.

Le Pomodoro permet d'organiser ses sessions de concentration.

## Liste des tâches

Une fenêtre affiche les tâches du jour.

Elle permet de :

- consulter les tâches à effectuer ;
- cocher les tâches terminées ;
- garder les objectifs visibles pendant la session de travail.

Les tâches proviennent du module **Mes tâches**.

## Bloc-notes

Un bloc-notes est disponible directement dans le Focus Workspace.

Il permet de noter rapidement :

- des idées ;
- des rappels ;
- des informations utiles pendant une session de travail.

Le bloc-notes reste accessible sans quitter l'espace de concentration.

## Objectif

Le Focus Workspace vise à limiter les distractions en réunissant :

- les tâches ;
- le minuteur ;
- la musique ;
- les vidéos d'ambiance ;
- les notes.

L'utilisateur n'a pas besoin d'ouvrir plusieurs applications simultanément.

## Cas d'utilisation

Le Focus Workspace peut être utilisé pour :

- une session de Deep Work ;
- une séance Pomodoro ;
- une journée de télétravail ;
- une session d'étude ;
- une session de développement informatique ;
- une session de comptabilité ;
- une session d'écriture.

## Limites documentaires

Les captures ne permettent pas de confirmer :

- la synchronisation du bloc-notes ;
- la sauvegarde automatique des notes ;
- le nombre maximal de vidéos YouTube ;
- la personnalisation de la durée du Pomodoro ;
- les statistiques des sessions.

Scalia ne doit pas inventer ces informations.
