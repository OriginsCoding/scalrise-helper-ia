# Bibliothèque Scalrise

## Objectif de la page

La page **Bibliothèque** permet de découvrir une sélection de contenus consacrés notamment à :

- la finance ;
- l'immobilier ;
- l'investissement ;
- l'entrepreneuriat ;
- le développement personnel ;
- la productivité ;
- le marketing ;
- le mindset.

La bibliothèque regroupe au moins deux types de contenus :

- des livres ;
- des vidéos.

## Accès à la page

1. Ouvrir Scalrise.
2. Dans le menu latéral, cliquer sur **Bibliothèque**.
3. La page s'ouvre à l'adresse `/library`.

## Résumé affiché

La page affiche des compteurs de suivi, notamment :

- le nombre de contenus possédés ;
- le nombre de contenus notés ;
- le nombre total de contenus présents dans la bibliothèque.

Les valeurs dépendent de l'utilisateur et du contenu disponible.

Scalia ne doit pas inventer ces nombres.

## Types de contenus

L'utilisateur peut basculer entre :

- **Livres** ;
- **Vidéos**.

La capture fournie présente principalement l'onglet **Livres**.

## Filtres disponibles

La bibliothèque peut être filtrée par catégorie.

Les catégories visibles incluent notamment :

- Tous ;
- Bourse ;
- Développement ;
- Entrepreneuriat ;
- Finances ;
- Immobilier ;
- Investissement ;
- Marketing ;
- Mindset ;
- Productivité.

Scalia peut expliquer que ces filtres permettent de réduire la liste aux contenus correspondant à un thème.

## Suggérer un livre

Chaque utilisateur peut suggérer un livre à ajouter à la bibliothèque.

La page affiche un bouton **Ajouter un livre**.

Cette action sert à proposer une idée de livre qui pourra ensuite être ajoutée au catalogue.

Scalia ne doit pas affirmer que la suggestion est publiée immédiatement sans validation, car le processus de validation n'est pas visible dans les captures.

## Présentation des livres

Chaque livre est affiché sous forme de carte.

Une carte peut afficher :

- la couverture ;
- le titre ;
- l'auteur ;
- une note ;
- le nombre de notes ;
- une courte description ;
- le nombre de pages ;
- l'année de publication ;
- le nombre de lecteurs ;
- le nombre de clics ;
- une ou plusieurs catégories.

## Statut de lecture ou de possession

Certaines cartes affichent une coche verte dans leur partie supérieure.

Cette coche indique qu'un statut positif est associé au livre pour l'utilisateur, par exemple un livre possédé ou suivi.

La capture ne permet pas de confirmer précisément toutes les règles associées à cette coche.

Scalia ne doit pas inventer sa signification exacte au-delà de ce qui est documenté.

## Interactions possibles

Selon les éléments visibles, un utilisateur peut notamment :

- consulter les livres disponibles ;
- filtrer la bibliothèque ;
- basculer entre livres et vidéos ;
- consulter les informations d'un livre ;
- voir les notes et statistiques associées ;
- suggérer un nouveau livre ;
- suivre son état personnel dans la bibliothèque.

## Exemples de réponses de Scalia

### Question : À quoi sert la bibliothèque ?

Scalia peut répondre :

> La Bibliothèque Scalrise permet de découvrir des livres et des vidéos sur la finance, l'immobilier, l'investissement, l'entrepreneuriat, la productivité et le développement personnel.

### Question : Puis-je filtrer les livres ?

Scalia peut répondre :

> Oui. Vous pouvez filtrer les contenus par catégorie, par exemple Bourse, Immobilier, Finances, Entrepreneuriat, Marketing, Mindset ou Productivité.

### Question : Puis-je proposer un livre ?

Scalia peut répondre :

> Oui. Depuis la page Bibliothèque, cliquez sur « Ajouter un livre » pour suggérer un ouvrage à ajouter au catalogue.

### Question : Quelles informations sont affichées sur un livre ?

Scalia peut répondre :

> Une carte de livre peut afficher la couverture, le titre, l'auteur, la note, une description, le nombre de pages, l'année de publication, le nombre de lecteurs, les clics et les catégories associées.

## Règles connues

- Chaque utilisateur peut suggérer des idées de livres à ajouter.
- La bibliothèque propose au moins des livres et des vidéos.
- Les contenus peuvent être filtrés par catégorie.
- Les compteurs affichés dépendent du catalogue et de l'utilisateur.
- Scalia ne doit pas inventer le processus de validation d'une suggestion.
- Scalia ne doit pas garantir qu'une suggestion sera acceptée ou publiée.

## Limites documentaires

Les captures ne permettent pas de déterminer :

- le formulaire exact de suggestion d'un livre ;
- les règles de validation ou de modération ;
- les droits nécessaires pour publier un contenu ;
- la signification exacte de chaque coche verte ;
- les actions disponibles après ouverture d'une carte ;
- les règles de notation ;
- la provenance des liens externes ;
- les éventuelles restrictions Premium ;
- les fonctionnalités précises de l'onglet Vidéos.

Scalia ne doit pas inventer ces informations.
